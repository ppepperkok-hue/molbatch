# 调用方式实测记录

本文件记录「怎么调用 ChemDraw / Chem3D 自带能力」的**实测结论**。每条都注明
是实测验证过的，还是仅从配置里读到、未验证的，避免后面误当既成事实。

状态标记：**[已实测]** 跑通过并有可复现证据 / **[仅读配置]** 只从文件里读到，
未实际执行 / **[未完成]** 开始测但中断。

## 1. ChemDraw COM 的真实能力

| 项目 | 结果 | 证据 |
|---|---|---|
| 创建文档 | **[已实测] 可用** | `Documents.Add()` → 原子=0 的干净文档 |
| **注入结构** | **[已实测] 可靠** | 剪贴板放 molfile + `Document.Paste()` |
| 打开已有文件 | **[已实测] 不可用** | `Documents.Open(路径)` 返回 ACS 模板（1 原子 1 文本 1 图形），与文件内容无关 |
| 执行菜单命令 | **[已实测] 无接口** | Application 仅暴露 `Quit`/`UpdateRunLevel`/`Documents`/`ActiveDocument`/`Preferences` 等 |
| 导出 | **[已实测] 可用** | `SaveAs(路径)`，按扩展名决定格式 |

`Documents.Open` 的失败证据：`.name` / `.smi` / `.txt` / `.cdx` 四种输入全部返回
同样的「1 原子 1 键 1 文本 1 图形」，即与文件内容无关，是模板而非解析结果。

### 批量注入实测（5 个分子，全部成功）

| 名称 | SMILES 来源 | 原子 | 键 | 产出 .cdx |
|---|---|---|---|---|
| aspirin | PubChem | 13 | 13 | 2382 B |
| caffeine | PubChem | 14 | 15 | 2635 B |
| benzene | PubChem | 6 | 6 | 1506 B |
| ibuprofen | PubChem | 15 | 15 | 2299 B |
| glucose | PubChem | 12 | 12 | 3098 B |

原子数均等于重原子数，说明结构被正确解析注入。

**结论**：可靠自动化链路为
`Documents.Add()` → 剪贴板 molfile → `Paste()` → `SaveAs()`

## 2. Name=Struct（名称转结构）在 GUI 可用

**[已实测]** 用户手工验证功能可用。

- 菜单：`结构 → 将名称转换为结构(C)`，快捷键 `Shift+Ctrl+N`
- 反向：`结构 → 将结构转换为名称(S)`，快捷键 `Alt+Ctrl+N`
- 定义：`Menus.xml` 中 `MenuItem_ConvertNameToStructure`
  / `<Command command="convertNameToStructure"/>`
- 画布右键菜单里也有同一条命令
- 菜单栏助记键：`文件(F)` `对象(O)` `结构(S)` `文本(T)` `曲线(C)` `颜色(A)`
  `插件(P)` `窗口(W)` `帮助(H)`（从 Menus.xml 的 CDATA 读出）

**限制**：COM 没有命令执行接口 → **[未完成]** UI 自动化触发方案未验证。

## 3. ChemDraw 支持的导入格式（官方类型表）

`cdx` / `cdxml` / `mol` / `mol V3000` / `sd` / `rxn` / `tgf` / `skc` / `msm` /
`smd` / `ct` / `cml` / `smiles` / `inchi` / `inchikey` /
`chemical/x-name` / `chemical/x-htmlname` / `helm` / `gif` / `png`

`chemical/x-name` 与 `chemical/x-htmlname` 是 Name=Struct 的入口类型，但
**无法通过 COM 或文件打开触发**（见第 1 节的 `Open` 失败）。

## 5. Chem3D 的自动化能力

**[已实测] 基本不可用**：

- COM 实例化能得到对象，但反射只有 .NET 基类成员
  （`Equals` / `GetType` / `GetHashCode` / `CreateObjRef` / …），**无业务接口**
- 只能走 GUI
- 力场参数文件齐全（`C3D Items\` 下有 MM2 / MMFF94 / OPLS / SYBYL），
  说明引擎本身具备三维优化能力，只是没有对外自动化入口

## 6. ChemScript（官方 Python 接口）

- 位置：`...\ChemDrawApplications\ChemScript\Lib\`
- 提供 `Environment.Activate()`、`NameToStructureOptions`、
  `Environment.SetN2SDataFile()` / `SetS2NDataFile()` 等
- **[已实测] 当前不可用**：编译好的扩展只有
  `_ChemScriptForPy39.pyd` / `_ChemScriptForPy310.pyd`，
  与本机 Python 3.11 / 3.14 不匹配
- **恢复路径**：安装 Python 3.10 后此接口即可用，届时可绕过 UI 自动化
  直接调用官方 N2S/S2N 引擎（这是回避 UI 脆弱性的最佳方案）

## 恢复开发时的建议起点

1. 装 Python 3.10 → 试 `ChemScript` 的 `Environment.Activate()` 与 N2S 接口
   （若通，名称转结构就有了官方、稳定的批量入口，不必碰 UI 自动化）
2. 补测 ChemDraw 的 `2DTo3D` 命令能否自动化
3. 上面两条都不通时，退回 RDKit（PubChem/OPSIN 解析 + MMFF94 三维）
   —— 已证明可批量、可测试
