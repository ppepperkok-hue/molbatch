# molbatch — 批量化合物结构生成器

输入一列化合物名称，批量输出 **2D 结构图** 与 **3D 结构文件**。目标是操作简单、
能直接用于课程作业与实验报告。

核心决策：**复用本机已装的 ChemDraw / Chem3D 自带能力**，不自研化学绘图与
三维构象。因此立项阶段的第一要务是摸清「怎么调用它」，而不是实现功能本身。

---

## 一、调用方式可行性研究（已完成，含实测）

### 1. ChemDraw COM 的真实能力（实测结论）

| 项目 | 结果 | 证据 |
|---|---|---|
| 创建文档 | ✅ 可用 | `Documents.Add()` → 原子=0 的干净文档 |
| **注入结构** | ✅ **可靠** | 剪贴板放 molfile + `Document.Paste()` → 苯酚 7 原子 7 键，存盘 1681 B |
| 打开已有文件 | ❌ **不可用** | `Documents.Open(路径)` 返回的是 ACS 模板（1 原子 1 文本 1 图形），与文件内容无关；`.name`/`.smi`/`.txt`/`.cdx` 全是同样结果 |
| 执行菜单命令 | ❌ 无接口 | Application 仅暴露 `Quit`/`UpdateRunLevel`/`Documents`/`ActiveDocument`/`Preferences` 等，无命令执行 |
| 导出 | ✅ 可用 | `SaveAs(路径)` 按扩展名决定格式 |

**结论**：ChemDraw 的可靠自动化路径是
`Documents.Add()` → 剪贴板 molfile → `Paste()` → `SaveAs()`。

### 2. ChemDraw 支持导入的格式（官方类型表，用于说明标准能力）

`cdx` / `cdxml` / `mol` / `mol V3000` / `sd` / `rxn` / `tgf` / `skc` / `msm` /
`smd` / `ct` / `cml` / `smiles` / `inchi` / `inchikey` /
**`chemical/x-name`** / **`chemical/x-htmlname`** / `helm` / `gif` / `png`

其中 `chemical/x-name`（名称）与 `chemical/x-htmlname`（网页名称）是
**Name=Struct 引擎的入口类型**，但**无法通过 COM 触发**，见下。

### 3. Name=Struct（名称转结构）在 GUI 里确认可用

- 菜单位置：`结构 → 将名称转换为结构(C)`，快捷键 **`Shift+Ctrl+N`**
- 反向：`结构 → 将结构转换为名称(S)`，快捷键 `Alt+Ctrl+N`
- 定义文件：`...\ChemDraw\GUI\Common\XML\Menus\Menus.xml`
  （`MenuItem_ConvertNameToStructure` / `<Command command="convertNameToStructure"/>`）
- 画布右键菜单里也有同一条命令
- 用户已实测该功能可用

**问题**：COM 没有暴露命令执行接口，因此无法直接用 COM 触发这条命令。

### 4. Chem3D 的自动化能力（实测结论）

| 项目 | 结果 |
|---|---|
| COM 实例化 | 能创建/连上，但**反射出来只有 .NET 基类成员**（`Equals`/`GetType`/…），无任何业务接口 |
| PowerShell 直调 | 不可行 |
| 可用力场参数文件 | MM2 / MMFF94 / OPLS / SYBYL 均在 `C3D Items\` 下，说明引擎具备三维优化能力 |

**结论**：Chem3D 的三维能力**无法通过 COM 驱动**，只能走 GUI。

### 5. ChemDraw 自身的 3D 入口

- `结构 → 3&D 清理`（`<Command command="2DTo3D"/>`，菜单项 `MenuItem_2DTo3D`）
- `结构 → 添加3D属性`（角度/二面角/距离/平面 等子项）
- `视图 → 显示 Chem3D 热链接窗口`（`<Command command="toggle3DWindow"/>`）

即 **ChemDraw 内部就能给结构加上三维坐标**，不一定要开 Chem3D。

### 6. ChemScript（官方 Python 接口）现状

- 位于 `...\ChemDrawApplications\ChemScript\Lib\`
- 提供 `Environment.Activate()`、`NameToStructureOptions`、
  `Environment.SetN2SDataFile()` / `SetS2NDataFile()` 等
- **但编译好的扩展只有 `_ChemScriptForPy39.pyd` / `_ChemScriptForPy310.pyd`**
- 本机 Python 为 3.11 与 3.14 → **当前不可用**；若安装 Python 3.10 则可用

## 二、已确认的决策

**名称 → 结构**：解析用现成库（PubChem / OPSIN），呈现与三维用 ChemDraw。
理由：已实测注入链路稳定、可测试、能批量；不赌 UI 自动化的脆弱性。

**三维**：先验证 ChemDraw 的「3&D 清理」能否自动化；通则走它，不通则退回
RDKit MMFF94（并注明为计算值）。

两条决策都已由用户确认。
